# Plugins

Plugin manifests normalize MCP, HTTP, CLI, and database connections into typed tools. Manifests contain secret slots and opaque references only—never credentials. The synthetic HTTP example proves that a new supported HTTP connection can be introduced as content without a core-code branch.

`workstation` placement may be authored and compiled, but it remains unavailable until the workstation broker checkpoint. Runtime implementations must fail closed rather than silently move a tool between placements.
