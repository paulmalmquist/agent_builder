# Planning archive

This directory preserves sanitized design inputs that explain how Paul OS evolved. These artifacts
are historical planning records, not current implementation contracts. Current behavior is defined
by source, generated OpenAPI, migrations, tests, and accepted architecture decision records.

## Contents

- `agent-builder-foundation-summary.md` — sanitized summary of the original reuse-first product
  concept.
- `certification-champion-challenger-prompt.md` — design prompt for certification, governed
  promotion, library search, and single-shot authoring.
- `motion-polish-blueprint-prompt.md` — motion, disclosure, and blueprint-canvas visual direction.
- `open-source-landscape-notes.md` — archived exploration of reusable public projects and missing
  platform capabilities; claims require fresh verification before use.
- `operational-agent-proving-catalog.md` — accepted follow-on validation scope defining 16
  substantial data and synthetic-manufacturing agents across five authority rungs.
- `phase-2-quiet-console-plan.md` — the initial quiet-console, Plugin, reuse, and managed-workstation
  proposal that informed the recovery-first implementation plan.
- `attention-console-mockup.html` — static, dependency-free Attention surface concept.

Raw images and conversational source material are intentionally excluded from Git. Local reference
copies belong in the ignored `.local/reference/` directory. Do not publish private URLs, QR codes,
organization-specific identity, real source names, identifiers, or retrieved source content when
updating this archive.

Preserve the design language—matte black, restrained purple, instrument typography, progressive
disclosure, and reduced-motion support—without carrying forward third-party identity.
